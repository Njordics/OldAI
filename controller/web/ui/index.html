AI Cluster

Sign in with the Controller's admin token.

On the Controller: sudo cat /var/lib/aicluster/controller/admin.token

Seeing a certificate warning?

The Controller signs its own certificate with this cluster's private CA. Trust the CA once on this computer and the warning goes away. The CA can only vouch for local network names (.local, localhost) and private IP addresses, never for internet sites.

Download cluster CA

Check the fingerprint matches the one on the Controller's console:

Windows (Chrome, Edge)

certutil -user -addstore Root aicluster-ca.crt

macOS (Safari, Chrome)

security add-trusted-cert -r trustRoot -k ~/Library/Keychains/login.keychain-db aicluster-ca.crt

Linux (Chrome)

certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n aicluster -i aicluster-ca.crt

Firefox

Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, then tick "Trust this CA to identify websites".

Then restart the browser. Full guide: docs/dashboard-trust.md.
